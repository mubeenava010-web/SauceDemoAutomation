# SauceDemo (Swag Labs) - Automation & Manual Testing Project

## Project Overview
This repository contains the end-to-end testing framework for the SauceDemo (Swag Labs) e-commerce application, covering both manual documentation and Selenium automation.

## Application Under Test
* **Application:** SauceDemo (Swag Labs)
* **URL:** https://www.saucedemo.com/

## Testing Scope
* Login Validation
* Product Catalog Navigation
* Cart Operations
* Checkout Workflow & Verification
* Logout

## Tools & Technologies
* **Manual Testing:** Test Plan, Test Case Design, Defect Logging
* **Automation:** Java, Selenium WebDriver, TestNG, Maven, Page Object Model (POM)
* **Defect Management:** Jira
